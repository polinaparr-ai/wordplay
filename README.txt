Wordplay — Scrabble solver

All application files, including the PERV/PERVS dictionary fix.

To continue editing in ChatGPT, attach this ZIP and describe your changes.

To run locally: extract this ZIP, open a terminal in the Wordplay folder, and run:
  python3 -m http.server 8000
Then open http://localhost:8000 in your browser.
Use a web server rather than double-clicking index.html because the solver uses a Web Worker.

Files: index.html (page), style.css (layout), app.js (interaction), engine.js (solver), solver-worker.js (background search), lexicon.js (dictionary), DICTIONARY.txt (attribution).

Live app: https://wordplay-polina-2310.polina-parr.chatgpt.site
